2. REQUISITOS EN EL OTRO DISPOSITIVO
-------------------------------------
- Unity 2019.4.16f1 con el modulo "WebGL Build Support" (mismo editor que
  uso yo; si instalas otra version, el build puede variar).
- PowerShell (incluido en Windows) para servir el juego.
- Un navegador moderno: Chrome o Edge (recomendados), Firefox 151+.
- ~12 GB de disco libres (proyecto + Library al importar + builds).

3. JUGAR ENSEGUIDA (sin tocar nada)
-----------------------------------
a) Descomprime este ZIP entero.
b) Entra en la carpeta "ultrakill-webport" y ejecuta:
       powershell -ExecutionPolicy Bypass -File .\serve-webgl.ps1
   (o el .bat del juego: dist\ULTRAKILL-WebGL-v20.1.zip -> descomprime ->
    JUGAR.bat)
c) Abre http://localhost:8000/?v=20
   - "PANTALLA COMPLETA" (no uses F11).
   - "NIVELES (F3)": menu para saltar a cualquier nivel.
   - Si el navegador dice ERR_CONNECTION_REFUSED, el servidor esta parado:
     relanzalo (es el paso b).
   - Si el raton no se queda bloqueado, pulsa una tecla o haz clic: Chrome solo
     concede el bloqueo dentro de un gesto del usuario.

4. TRABAJAR EN EL PROYECTO
--------------------------
a) Abre la carpeta ultrakill-webport\export\ExportedProject con Unity
   2019.4.16f1. La primera importacion tarda 15-20 min (no hay Library).
b) PARA RECONSTRUIR EL JUEGO (los bundles van aparte del player):
       Unity.exe -batchmode -quit -projectPath <ExportedProject> ^
         -logFile build.log -buildTarget WebGL ^
         -executeMethod WebGLBuilder.Build
   (build del player: ~7 min)
       Unity.exe -batchmode -quit -projectPath <ExportedProject> ^
         -logFile bundles.log -buildTarget WebGL ^
         -executeMethod WebGLBundleBuilder.BuildAct0
       ... y WebGLBundleBuilder.BuildAct1 (act-1 + prime) o BuildAll (todo).
   (cada bundle: 10-25 min segun el tamano)
c) TRAS RECONSTRUIR, copia:
       Builds\WebGLBundles\acts\act-0  ->  Assets\StreamingAssets\acts\act-0
       Builds\WebGLBundles\acts\act-1  ->  Assets\StreamingAssets\acts\act-1
       Builds\WebGLBundles\acts\prime  ->  Assets\StreamingAssets\acts\prime
   y lo mismo a Builds\WebGL\StreamingAssets\acts\ (lo que se sirve).
   Ojo: si cambias los shaders o las escenas, hay que RECONSTRUIR los bundles
   (los shaders y los materiales van dentro del bundle, no solo en el player).
d) Si tocas la pagina (WebGLTemplate.html), copiala a
   Builds\WebGL\index.html (o relanza el build del player, que ya lo hace).
e) MapLoader.WebGLBundleQuery ("?v=20"): subela cuando cambien los bundles
   para que el navegador no sirva los viejos.
f) El servidor sirve Builds\WebGL (no el dist).

6. HERRAMIENTAS DE DIAGNOSTICO (tools/)
---------------------------------------
- cdp_lib.ps1, chrome_probe.ps1, test_*.ps1, diag*.ps1:
  controlan un Chrome real por el protocolo DevTools (CDP) para probar el
  juego: estado del raton/fullscreen/teclado, eventos de pointer lock,
  consola del juego y capturas.
  Uso:  powershell -ExecutionPolicy Bypass -File .\tools\chrome_probe.ps1
  (necesita el servidor levantado en el 8000).
- scene_probe.ps1, scene_chain.ps1, scene_objs.ps1, proof_names.ps1:
  analizan el YAML de las escenas (mapeo de niveles, integridad, manifest).
- install_shaders*.ps1, gen_variants*.ps1: shaders.
- check_scene_integrity.ps1: % de referencias rotas por escena.
